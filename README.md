# DPI-HT-01 Audit Report

This repository contains the local static audit-report deliverable and its final supporting package for Divorce Party International Ltd.

The report is an English presentation layer for the completed final package. Financial statements, schedules, reconciliations, and conclusions remain preliminary and qualified where the underlying evidence is incomplete or unresolved.

## Run locally

```powershell
python site/serve.py
```

Open the local report at:

- `/` — audit report and decision brief
- `/review/` — Guided Review Trail

The static build is committed in `site/dist`. No deployment configuration, publication, or external source links are included in this repository setup.
